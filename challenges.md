# Challenges

This file is compulsory. Write a truthful account of the work, including places where you got stuck. A challenge can be a confusing data shape, a bug that was hard to reproduce, an unfamiliar library, or an approach that did not work.

## Challenge 1
- What happened?
- What did you try first, and what did you observe?
- How did you find the cause?
- What change resolved it?
- What would you do differently next time?

## Other challenges
Add a section for each significant obstacle. If you had no major blockers, explain what you checked to confirm the work was straightforward.
